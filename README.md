# All of my fuh good skills

A collection of my personal AI agent skills.

## Contents

This snapshot contains 182 skills from my personal global Amp skills
repository, including the 29 Roblox Brain skills, exported on October 5, 2026.
The `docx` and `pptx` skills are excluded because their bundled licenses
prohibit redistribution. They remain unchanged in my personal Amp repository.
Official Amp skills and plugin-bundled skills are not part of this collection.

Each top-level directory is a skill with a `SKILL.md` entry point. Supporting
references, scripts, templates, and license files remain beside their skill.
Copy the whole skill directory when installing it, not just `SKILL.md`.

## Provenance and licenses

The skill files are preserved unchanged from the Amp repository. This is a
snapshot, not an automatic synchronization with Amp or the upstream authors.
Bundled license and attribution notices are retained; this repository does not
apply a blanket license to third-party skills or grant additional reuse rights.

The import checks file integrity and skill structure. It does not certify that
every bundled script runs or that every API example is current. Review a skill's
instructions, scripts, dependencies, and applicable license before using it.
